위치 기록 (지도 앱 타임라인)●✕△✕간 곳은 남지만 의미가 없다. 날짜를 알아야 찾을 수 있다
사진 앱△✕●△사진을 찍은 순간만 기억한다. 사진 없는 하루는 비어 있다
일기 · 라이프로그 앱✕●△✕직접 써야 한다. 대부분 며칠 만에 멈춘다
시간 기록 앱●△✕✕시간 비중은 보이지만, 지난 기억을 꺼내 쓸 수는 없다
HARU●●●●입력 0 · 장소에 의미 · 사진 자동 연결 · 근거 있는 답
INPUT 0노력 0의 기록앱을 켜 두기만 하면 머문 곳이 하루 단위로 쌓인다
MEANING좌표 → 기억 단위머문 곳에 태그를 붙여 "카페 45분", "강원도 2박 3일"로 바꾼다
MEDIA장소마다 사진 · 영상촬영 시각과 위치로 방문에 자동으로 묶는다
