# 하루 (Haru) — 서비스 기획서

> 나의 하루를 위치·사진·날짜로 기록하고, AI가 무엇을 했는지 추론해주는 개인 라이프로그 앱

**버전** 0.1 | **작성일** 2026-11-14

---

## 1. 서비스 개요

| 항목 | 내용 |
|---|---|
| 서비스명 | 하루 (Haru) |
| 한 줄 설명 | 핸드폰이 기억하는 나의 하루 |
| 핵심 가치 | 아무것도 입력하지 않아도 하루가 자동으로 기록된다 |
| 타깃 유저 | 자신의 시간과 행동 패턴을 되돌아보고 싶은 사람 |

## 2. 핵심 기능

### 2-1. 자동 수집
- **위치 (GPS)**: 백그라운드에서 15분 이상 머문 곳을 "장소 방문"으로 기록
- **사진 (EXIF)**: 촬영 시각·위치 메타데이터를 자동 연동
- **날짜/시간**: 타임스탬프 기반 타임라인 자동 생성

### 2-2. AI 추론 (LLM)
- 위치명 + 머문 시간 + 사진 태그를 GPT-4o mini에 전달
- "무엇을 했는지" 추측 + 확신도(%) 표시
- 사용자가 틀린 추론을 직접 수정 가능 → 수정 데이터로 개인화 개선

### 2-3. 도넛 차트 (장소 비중 시각화)
- **하루 / 한 주 / 한 달 / 1년** 4개 탭 전환
- 장소 카테고리별 체류 비중을 도넛 차트로 표시
- 하단에 AI 요약 텍스트 제공

### 2-4. 자연어 질문 (Q&A)
- 예: "올해 강원도 몇 번 갔지?" → "8번이에요. 마지막: 2026-10-03 · 속초 해변"
- 방문 횟수, 가장 많이 간 곳, 특정 기간 행동 패턴 등 조회 가능
- **LLM 방식**: 사용자 질문 → 백엔드 → AWS Bedrock → 방문 DB RAG → 자연어 응답
- 앱에서 질문을 입력하면 API로 전달, Bedrock이 방문 이력을 컨텍스트로 답변 생성

## 4. 기술 스택

### 프론트엔드 (모바일 앱)
**React Native** (iOS + Android 단일 코드베이스)

| 역할 | 라이브러리 |
|---|---|
| 위치 수집 (백그라운드) | `react-native-background-geolocation` |
| 사진 접근 | `react-native-photo-library` / `expo-media-library` |
| 도넛 차트 | `react-native-svg` + `d3-shape` |
| 로컬 저장 | `react-native-mmkv` (빠른 K-V) + `SQLite` (방문 이력) |
| 상태 관리 | Zustand |
| 내비게이션 | React Navigation v7 |
| 자연어 입력 | 커스텀 TextInput → 백엔드 API 호출 |

> iOS: `NSLocationAlwaysAndWhenInUseUsageDescription` 권한 필수  
> Android: `ACCESS_BACKGROUND_LOCATION` 권한 필수

### 백엔드
| 역할 | 기술 |
|---|---|
| API 서버 | Node.js + Fastify (또는 Python FastAPI) |
| 장소 인식 | Google Places API (Reverse Geocode) |
| 클러스터링 | 15분 이상 반경 100m 이내 = 1 방문 |
| AI 추론 | OpenAI GPT-4o mini (입력: 위치명 + 시간대 + 사진 태그) |
| 저장 | PostgreSQL + PostGIS (위치 쿼리) |
| Q&A | **AWS Bedrock** (Claude) + 방문 DB RAG | 자연어 질문 → 방문 이력 컨텍스트 → LLM 응답 |

### 프라이버시 원칙
- 위치 데이터는 기기 내 처리 우선
- 클라우드 업로드 시 E2E 암호화
- LLM 전송 데이터에 개인 식별 정보 미포함

## 5. 데이터 모델

```
Visit {
  id: UUID
  place_name: String          // "스타벅스 역삼점"
  place_category: Enum        // HOME | CAFE | GYM | TRANSIT | OTHER
  lat, lng: Float
  arrived_at: DateTime
  left_at: DateTime
  duration_min: Int
  photos: [PhotoRef]
  ai_activity: String         // "집중 작업"
  ai_confidence: Float        // 0.87
  user_correction: String?    // 사용자 수정값
}

Photo {
  id: UUID
  taken_at: DateTime
  lat, lng: Float
  visit_id: UUID?
}
```
